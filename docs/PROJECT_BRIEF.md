# GPhotosAlbumTool
a tool to manage google albums

google photos have API. looking to use the API to create a better tool to create or update other albums based on photos in selected album.
Currently, the normal workflow to move a photo from one album to another either:
- see photos in thumbnail mode, multi-select what you like and then add all selected to a new or existing album. Problem: you don't see full size photo to properly judge with one is better.
- See full-size photos and add them to a new or existing album one by one. Problem: for large albums it's time-consuming.

Looking to build a tool using  Google API to make it easy create "selected photos album" based on a largee albums
